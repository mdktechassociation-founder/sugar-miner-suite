MineHub

A SUGAR wallet, a wrapped APK and an earnings view for apps that are free in exchange for spare computing power. The user sees a notification the whole time and can stop it with one tap — that part is not configurable here, because it is what makes this a business model instead of malware.

Everything below happens on this machine. The server never sees a private key: only the address, which is all mining needs.

1 Create the wallet that receives the mining

The key is generated in this page with the browser's own random source, using Sugarchain's parameters (bech32_hrp = "sugar", WIF prefix 0x80). The address must be one you can spend from — never an exchange deposit address, and never a wallet someone else holds.

2 Wrap your app

Wrap = compile your app together with the SDK and your address. It is a build, not an injection: nothing is patched into a finished binary and nothing is re-signed.

“I only have the APK” — why that cannot work

      
Because a Flutter APK is already compiled into one AOT snapshot
        (libapp.so). The miner is Dart code with FFI into a native library, and
        Dart cannot be added to a snapshot that has already been compiled — the source is not
        in the APK, and a dex/smali patch cannot reach Dart. For a Flutter APK the operation is
        impossible, not merely refused.

      
And the general rule still applies to every other kind of APK: to put
        anything into a finished binary you must decompile it, rebuild it and re-sign it with a
        different key. That breaks the app's own update path (the store signature no longer
        matches), gets it flagged as repackaged, and for someone else's app it is exactly the
        malware technique — with no way to verify that an upload is yours.

      
Two things do work: if the APK is yours, wrap your project's source
        (above) — the SDK compiles in, and the build keeps your signing key. If you cannot build,
        MineHub can generate a small host app instead: a fresh Flutter project that ships
        the miner with your branding, which you can distribute on its own.

      
And the universal limit, worth saying out loud: Play Store bans
        on-device mining, iOS allows no background CPU work at all. Sideloading, enterprise and
        your own fleet are where this ships.

What this platform will not do

    

      
no stealth There is no switch to hide, silence or
        delay the mining notification. Without it Android kills the miner anyway, and mining the
        user cannot see is cryptojacking — malware charges, store bans, and pools that blacklist
        the address.

      
no key custody MineHub generates wallets in your
        browser and never stores a private key. If you lose it, the SUGAR is unreachable forever;
        that is the trade for nobody else being able to take it.

      
no repackaging Compiled APKs are refused, with the
        reason shown. Wrapping means compiling your source.

      
no minimums promised One phone does 100–400 H/s;
        at a 25% duty cycle that is cents per month. This covers a small app's costs at best.
        Anyone promising more from a phone is selling something else.
